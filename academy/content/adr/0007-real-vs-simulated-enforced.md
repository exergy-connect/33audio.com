## Context

This site is portfolio evidence. Example numbers presented as measurements would undermine all of it, and credentials for live telemetry are not configured yet.

## Decision

Every dataset has `kind: "real"` (with `source` and `collected_at`) or `kind: "simulated"` (with `make_real` steps). The build refuses anything else, renders a REAL TELEMETRY or SIMULATED / EXAMPLE DATA badge on every chart and trace, and fails if a chart reaches a page without a badge. Real datasets live in `academy/data/real/` (not committed), generated by the measurement tools; CI generates them from `wrangler pages dev` on each run.

## Consequences

- A reader can always tell measured from illustrative.
- Local measurements are labeled with their environment, so they are not mistaken for edge latency.
- Live widgets label `request.cf` values from `wrangler dev` as simulated, because Miniflare fills them with placeholders.
